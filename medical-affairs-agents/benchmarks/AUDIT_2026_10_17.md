# Quality & Performance Audit — October 17, 2026

**Status:** Engineering audit complete; scientific content **not** independently adjudicated.

## What was found and corrected

| Finding | Why it matters | Corrective action |
|---|---|---|
| Abstract numbers were previously searched separately throughout the whole abstract | A proposed HR and a CI for another endpoint could be falsely marked "found" | `abstract_statistic_verifier.py` now requires effect estimate and its CI to appear in one local expression, with the nearest explicitly named endpoint assessed separately |
| Original RCTs say "hazard ratio **for progression or death**" and may use "hazard ratio (HR)" | An overly strict pattern missed valid results (poor recall) | Support generic hazard-ratio modifiers and aliases; test on adversarial synthetic formats |
| Invasive disease-free survival could be mistaken for ordinary disease-free survival | Incorrect endpoint labeling can invalidate a claim even when all numbers match | Require separate `iDFS` and `DFS` context checks; ambiguous results remain flagged |
| Source check was based on numeric token co-occurrence | A green source status looked stronger than its actual evidence | Export separate PMID+DOI, co-located estimate/CI, nearby endpoint and trial registration fields; none count as clinical approval |
| TROPION-Breast02 endpoint role was left as "primary_or_coprimary_verify_protocol" | Original publication clearly defines **dual primary endpoints PFS and OS** | Fixed to `dual_primary`; preserve PFS HR 0.57 with **99% CI** and separate OS HR 0.79 with **95.01% CI** as original-source review leads |
| Public abstract report underemphasized pulmonary toxicity and trial negative findings | Omission creates a skewed medical-affairs summary | Added [Safety & negative-result review priorities](SAFETY_REVIEW_PRIORITIES.md) with original PubMed source links, reported fatal ILD events, and the BEGONIA missed prespecified response objective |
| Ten serial Europe PMC metadata requests | Unnecessary network latency and more failure opportunities | Replaced with **one bounded, deduplicated, source-checked batch request**; individual fallback only if a PMID is genuinely missing |

Recent batched + strict result-checking runs: **2.918 s, 2.819 s, and 3.186 s** (GitHub Actions). Median observed: **2.918 s**.

The median new run was about **73% faster** than the old 10.955 s serial run (about **3.8x** throughput for this one task), **not** a guaranteed runtime improvement. It excludes paper discovery, full-text access, expert interpretation, corrections, approval and actual managerial reading time.

## Why the three numerical/endpoint flags are not auto-fixed

- **DESTINY-Breast03:** the target HR and CI are locally present, but its link to the proposed PFS endpoint is not explicitly resolved by the nearest abstract endpoint context. The result can still be scientifically correct; automated verification must abstain rather than guess.
- **DESTINY-Breast04:** the reference label does not contain CI limits. The extractor cannot invent a 95% CI or infer it from another article.
- **DESTINY-Breast05:** the original abstract reports iDFS and DFS analyses with similar numerical results. Automatic pairing from abstract alone risks selecting the wrong endpoint or result.
- **TROPION-Breast02:** the proposed PFS effect/CI and endpoint are located, but the original PubMed metadata linkage to NCT05374512 is incomplete. The FDA provides an independent regulatory cross-reference, which is recorded separately.

These are four **distinct kinds of incompleteness**, not all failures of the same numeric extractor. The total 7/10 local statistic matches includes TROPION-Breast02, while only 6/10 pass the stricter original PubMed identification and endpoint-candidate chain. **Do not relabel this 6/10 as an accuracy score.**

## Limits that remain

- This is a **development set of 10 selected original study families**, not an unseen external test and not a comprehensive systematic review.
- Source-token and source-context matches do **not** validate arms, denominators, subgroup, endpoint hierarchy, data cutoff, multiplicity, RoB 2, safety completeness, or treatment efficacy.
- Full source tables, figures, supplements and publisher corrections still need independent verification; reuse rights determine how content may enter the pipeline, **not** whether a paper's science is strong.
- A useful Medical Affairs report must cover **negative outcomes and toxicities alongside positive endpoints**, including ILD/pneumonitis and the source-specific treatment-related risks.
- An accuracy percentage requires a frozen, trial-family-disjoint test corpus and **two independent, qualified reviewers** with adjudicated result-level gold labels.
- The public audit now fails closed if even one selected original PMID+DOI record is mismatched or unavailable. This behavior has a synthetic regression test.
- Hard-coded candidate values belong only in the *provisional development dataset* and cannot be presented as autonomous Agent reasoning.
- Clinical risk assessments and any external report require scientific review and legal/content-rights checks.
