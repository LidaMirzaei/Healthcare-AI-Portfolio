# Month 1 — Manufacturing Data Analytics

October 16 – November 15, 2026.

Learn Python, pandas, SQL, descriptive statistics, batch identifiers, time-series basics, yield, scrap, OEE, deviations and data provenance. Practice using synthetic manufacturing process data only.

First task: build a table of 20 synthetic batches with temperature, pressure, mixing time and a simulated quality result. Report missing values and correlations; never infer causality from correlations alone.

Resources: https://www.kaggle.com/learn/python and https://pandas.pydata.org/docs/getting_started/intro_tutorials/
