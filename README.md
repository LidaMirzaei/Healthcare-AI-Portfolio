# Healthcare AI Portfolio

**A six-month, hands-on AI and data science learning portfolio**  
**October 16, 2026 – April 16, 2027**

Maintained by Lida Mirzaei. Goal: build reproducible, technically defensible healthcare/life-sciences data science and ML engineering projects suitable for job applications. This is an **independent educational portfolio**, not affiliated with or endorsed by Daiichi Sankyo.

## Start here: Day 1

Run locally with Python 3.10+:

```bash
git clone https://github.com/LidaMirzaei/Healthcare-AI-Portfolio.git
cd Healthcare-AI-Portfolio
python -m pip install -r requirements.txt
python 01-Python-SQL-Statistics/day01_patient_data.py
```

Read [Month 1 instructions](01-Python-SQL-Statistics/README.md).

The Day 1 dataset is **synthetic and tiny**. The output cannot establish clinical treatment efficacy or causal effects. Future examples will use properly licensed public data or synthetic data only. No private patient or employer data will be uploaded.
